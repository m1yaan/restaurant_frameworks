# Сервис управления ресторанными заказами — ПР11 — формы и CRUD

Финальная версия включает ModelForm для клиента и заказа, создание/редактирование/удаление, проверку активности и вместимости стола, проверку даты бронирования (прошлая дата запрещена), загрузку фото блюда через ImageField и Pillow. Заполните справочники через `/admin/`.

## Запуск
Для консольных этапов: `python main.py`.

Для Django-этапов:
1. Создайте виртуальное окружение: `python -m venv .venv`
2. Активируйте его.
3. Установите зависимости: `pip install -r requirements.txt`
4. Выполните миграции (если предусмотрены): `python manage.py migrate`
5. Запустите сервер: `python manage.py runserver`

Язык интерфейса Django: русский (`ru-ru`).
